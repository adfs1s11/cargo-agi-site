# M&M 통합 운송 관제

## 로그인

초기 확인용 계정은 ADMIN / 1234입니다. 로그인 후 관리자 페이지에서 아이디와 비밀번호를 변경할 수 있습니다. 현재 로그인과 계정 설정은 브라우저별로 적용되며, 서버 인증을 대신하지 않습니다. 실제 운영용 공통 인증은 별도 서버가 필요합니다.

## 샘플 자료

자료가 없는 브라우저에는 가상 기사 12명과 최근 120일 배차 샘플을 넣습니다. 실제 이름·연락처·차량번호와 운영 원장은 포함하지 않습니다. 기존 자료가 있는 경우 자동 추가하지 않습니다. 관리자 페이지에서 샘플 넣기·삭제를 할 수 있으며, 직접 업로드한 자료는 유지됩니다.

데이터는 현재 브라우저에 저장됩니다. 설정에서 전체 백업을 받아 보관하세요.

## 정산·마감

정산·마감 메뉴에서 월을 선택하고 단가 사전을 등록하거나 기존 엑셀을 가져오세요. 매출(거래처 청구)과 매입(기사 지급)은 서로 다른 단가로 관리합니다. 브랜드·차종·상품분류·거래처·기사·출발지·도착지·장비유형·거리·적용기간 조건을 사용할 수 있습니다.

기본요금은 우선순위와 조건의 구체성을 비교해 1개를 적용합니다. 동순위 충돌은 확인 대상으로 표시합니다. 추가요금은 일치하는 항목을 모두 합산합니다. 대당/건당/km당을 구분하며 공급가와 부가세는 별도 입력·계산합니다. 원 단위로 반올림합니다.

마감 엑셀 가져오기는 단가 사전과 배차별 정산 확정금액을 지원합니다. 시트·헤더 행·열 매핑을 선택하고 미리보기를 검토한 뒤 반영하세요. 확정금액은 운송일과 차대번호, 필요 시 기사·구간으로 원장 1건에 연결합니다. 모호한 행은 반영하지 않습니다. 입력 양식은 메뉴에서 내려받을 수 있습니다. 실제 업체 양식은 열 매핑 확인이 필요합니다.

미배정·단가 없음·단가 충돌이 남아 있으면 월 마감을 확정할 수 없습니다. 마감 시 공급가·부가세·적용 단가 근거를 고정 보관합니다. 수정하려면 사유를 남겨 마감을 해제하고 재마감하세요. 정산내역·거래처별·기사별 내역은 엑셀로 내려받을 수 있습니다. 정산자료는 브라우저에 저장되며 전체 백업에 포함됩니다. 현재 Google Sheets 연동은 정산자료를 공유하지 않습니다.

## 배차엔진

배차엔진 메뉴에서 6개월~3년 이력을 선택할 수 있으며 신규 설치 기본값은 2년입니다. 구간·차종·상품분류·장비 이력을 점수화하고, 이력이 부족한 기사는 같은 장비유형과 유사 적재대수·숙련도·거점의 기사 최대 3명 이력을 보조로 참고합니다.

기사 관리에서 숙련도·거점·운행 가능 시간·상품분류, 운송차량에서 장비유형·적재대수·허용중량·상품분류, 상품차량에서 분류·필요장비·최소숙련도·차량중량을 입력하세요. 미입력 값은 실제 제원으로 추정하지 않습니다. 지도 기반 공차거리와 여러 운송건의 동시 적재 배치는 별도 확인이 필요합니다.
