# M&M 통합 운송 관제

브라우저에서 배차판 업로드, 가배차, 기사 평가, 기사·차량 관리, 사고·클레임 기록을 처리합니다.

## 시작하기

1. 배차판에서 엑셀 또는 CSV 파일을 업로드합니다.
2. 기준일을 선택해 대시보드에서 배정·미배차 현황을 확인합니다.
3. 가배차에서 추천 배차를 실행하고 담당 기사를 검토한 뒤 확정합니다.
4. 설정에서 JSON 전체 백업을 받아 보관합니다.

처음 접속하면 빈 원장으로 시작합니다. 원장과 사진은 현재 브라우저에 저장되며 다른 기기로 자동 공유되지 않습니다. Google Sheets 연결은 설정에서 별도로 구성할 수 있습니다.

공개 코드에는 운영 원장, 기사 연락처, 안전관리 원본 자료가 포함되어 있지 않습니다.

대시보드는 배차·배정·미배차·투입 기사, 최근 추이, 권역·거래처·기사별 배정 현황을 제공합니다.
