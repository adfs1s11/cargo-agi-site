# Google Sheets 연동 (Apps Script)

M&M 통합 운송 관제의 원장을 Google 스프레드시트에 보관하는 백엔드입니다. 앱은 로컬 우선으로 동작하고, 이 웹앱을 통해 업로드/다운로드합니다.

---

## 1. 준비

1. Google Drive에서 새 스프레드시트를 만들고 이름을 `M&M 통합관제 원장`으로 지정합니다.
2. 주소창의 URL에서 파일 ID를 복사합니다.

```
https://docs.google.com/spreadsheets/d/  ← 이 사이의 긴 문자열  ←  /edit#gid=0
```

3. 스프레드시트에서 **확장 프로그램 → Apps Script**를 엽니다.
4. 이 폴더의 `Code.gs` 전체를 붙여넣습니다.
5. 아래 두 값을 수정합니다.

```js
const CONFIG = {
  TOKEN: '여기에_32자_이상_임의_문자열',   // 앱 설정에도 동일하게 입력
  SPREADSHEET_ID: '스프레드시트_파일_ID',
  DRIVE_FOLDER_ID: '',                    // 사진 업로드(2단계) 때 사용
  ...
};
```

6. `setup` 함수를 한 번 실행해 시트를 만들어도 되고, 첫 업로드 시 자동 생성됩니다.
   (편집기에서 함수 선택 → 실행 → 권한 허용)

---

## 2. 웹앱 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 유형: **웹앱**.
3. 설명: `M&M 통합관제 API`.
4. 실행 계정: **나**.
5. 액세스: **모든 사용자** (앱이 토큰으로 인증합니다).
6. **배포** → 나오는 **웹앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.
7. 앱의 **설정 → Google Sheets**에 URL과 TOKEN을 입력합니다.
8. **연결 테스트** → 스프레드시트 이름이 표시되면 성공입니다.
9. **전체 업로드**를 누르면 아래 시트가 자동 생성되고 데이터가 기록됩니다.

> 코드를 수정하면 **배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다.

---

## 3. 시트 구조

| 시트 | 내용 |
|---|---|
| `DRIVERS` | 기사 마스터(선호/기피 권역, 별칭, 상태) |
| `EQUIPMENT` | 운송차량(적재량, 보험·검사, 배정 기사) |
| `PRODUCTS` | 상품차량 시세 |
| `INCIDENTS` | 사고·클레임(사진 ID 목록, 비용, 상태) |
| `ASSIGNMENTS` | 가배차 초안/확정 |
| `DISPATCH` | 배차 원장(업로드 결과) |
| `IMPORTS` | 가져오기 이력 |

- 첫 행은 헤더이며 임의로 순서를 바꾸지 마세요.
- `preferred`, `photos`, `orderIds` 같은 배열은 JSON 문자열로 저장됩니다.
- `id`가 같으면 갱신, 없으면 추가합니다.

---

## 4. API

모든 요청은 `POST` + `Content-Type: text/plain` + 아래 JSON 형식입니다.

```json
{ "token": "…", "action": "list", "payload": { "table": "DRIVERS" } }
```

| action | payload | 설명 |
|---|---|---|
| `ping` | – | 연결 확인, 시트 수 |
| `list` | `{ table }` | 전체 행 조회 |
| `upsert` | `{ table, rows[] }` | 최대 500건 저장(앱은 200건씩 전송) |
| `delete` | `{ table, ids[] }` | 행 삭제 |
| `uploadPhoto` | `{ dataUrl, name }` | Drive 업로드(폴더 ID 필요) |
| `setup` | – | 시트/헤더 생성 |

응답: `{ "ok": true, "data": … }` 또는 `{ "ok": false, "error": "…" }`

---

## 5. 운영·보안

- **토큰은 32자 이상 임의 문자열**로 만드세요. URL과 토큰을 아는 사람은 데이터에 접근할 수 있습니다.
- 웹앱을 사내 계정으로 제한하려면 액세스를 **조직 내**로 바꾸고, 앱 대신 Google 로그인 세션을 사용하는 별도 인증이 필요합니다. 현재 구조는 토큰 방식입니다.
- Google 스프레드시트는 **시트당 1,000만 셀** 제한이 있습니다. 32열 기준 `DISPATCH` 약 30만 건이 한계이므로, 1~2년 전체를 한 시트에 미러링하지 말고 **최근 데이터만 동기화**하거나 연도별 스프레드시트로 분리하세요.
- 5,000건 이상 `DISPATCH`는 `list` 응답이 커집니다. Apps Script 응답은 약 50MB 제한이 있어 5~8만 건을 한 번에 내려받으면 실패할 수 있습니다. 연도별 스프레드시트로 분리하거나 `list`에 `limit`·`offset`을 추가하세요.
- 사진을 Drive로 이전하는 2단계에서는 `DRIVE_FOLDER_ID`를 설정하고, 앱의 사고 저장 로직에서 `uploadPhoto`를 호출하도록 확장합니다.
- 원본 배차판(기존 메인배차판)은 이 백엔드가 **읽지도 쓰지도 않습니다.** 완전히 분리된 원장입니다.

---

## 6. 문제 해결

| 증상 | 확인 |
|---|---|
| `인증 토큰이 올바르지 않습니다` | Code.gs의 `TOKEN`과 앱 입력값이 같은지(공백 포함) |
| `SPREADSHEET_ID를 설정하세요` | `PUT_…` 자리표시자가 남아 있는지 |
| 연결 테스트가 시간 초과 | 배포 액세스가 **모든 사용자**인지, `/exec` URL인지 |
| 업로드 중 401/HTML 응답 | 웹앱을 다시 배포했는지, 로그인 계정이 실행 계정과 같은지 |
| 한글 깨짐 | 앱은 UTF-8로 전송합니다. 시트 글꼴/로캘은 무관합니다. |
